# Maintenance Pro v2.5.3

## Responsive / Modal hotfix

- Manual Duty modal is viewport-safe on desktop, tablet and mobile.
- Header and close button remain visible.
- Form body scrolls internally.
- Action footer remains reachable and sticky.
- Compact technician picker uses two columns on desktop and a shorter internal list.
- Escape closes major dialogs and the page behind a dialog is scroll-locked.
- Create Task, Task Detail, PM, Checklist, Technician and Team dialogs use dynamic viewport height.
- Mobile More menu is capped to the visible viewport.

## Backend behavior unchanged

- Duty creation remains manual-only.
- LINE cron remains automatic.
- MPR support and the 20-person technician master remain unchanged.
